---
title: RexRankMenu
description: Buy the next LuckPerms group from a menu on Paper, Purpur, and Folia.
---

RexRankMenu sells the next group on a LuckPerms track. The group list is loaded from LuckPerms when a player opens the menu, so a track edit does not require a new GUI file.

`ranks.yml` only dresses those groups: price, currency, name, lore, slot, material, and custom model data. A group with no section uses the default material and the group name.

Names and other player-facing lines use MiniMessage. Legacy `&` codes, `&#RRGGBB`, and `#RRGGBB` also work.

## Files

```
plugins/RexRankMenu/
  config.yml
  ranks.yml
```
