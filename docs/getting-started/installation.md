---
title: Installation
description: Put RexRankMenu on a Paper, Purpur, or Folia server.
sidebar:
  order: 1
---

1. Download the jar.
2. Put it in the server `plugins/` folder.
3. Start the server once so `plugins/RexRankMenu/config.yml` and `ranks.yml` are written.
4. Set `settings.track` to a LuckPerms track that already exists.
5. Edit prices in `ranks.yml`.
6. Run `/rexrankmenu reload`, or restart.

LuckPerms has to be installed. If it is not, RexRankMenu logs one line and disables itself. Vault and PlaceholderAPI are optional and follow the currencies you configure.
